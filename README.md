# e-plantShopping

## Paradise Nursery Shopping Cart Application

This repository contains the final project for the IBM Front-End Developer React course.  
The application is a plant shopping cart built using React, Redux Toolkit, and Vite.

### Features
- Landing page with a “Get Started” button
- Navigation bar with links to Home, Plants, and Cart
- Product listing page with plant cards (image, name, description, cost)
- Two plant sections (e.g., Aromatic Plants, Medicinal Plants)
- Add to Cart functionality
- Cart page with quantity controls and delete button
- Continue Shopping and Checkout buttons
- Dynamic cart total using Redux state management

### Technologies Used
- React
- Redux Toolkit
- JavaScript
- CSS
- Vite
